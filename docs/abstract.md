# Abstract

**Context:** The rapid digitization of real estate marketplaces has introduced complex fraud patterns that threaten platform integrity and user trust. Traditional detection methods, which analyze listings in isolation, often fail to identify sophisticated fraud rings that coordinate across multiple accounts and devices.
**Objective:** This thesis proposes and evaluates a hybrid fraud detection framework specifically designed for online real estate platforms. It aims to determine whether integrating relational features learned via Graph Neural Networks (GNNs) with Gradient Boosting classifiers can outperform state-of-the-art tabular baselines.
**Methodology:** A heterogeneous graph was constructed from 804,717 real-world events, linking listings via shared attributes such as devices, IPs, and contact details. A GraphSAGE model was trained using a supervised objective to generate node embeddings, which were then combined with 65 tabular features to train an XGBoost classifier. The framework was evaluated using a rigorous "expanding window" backtest to assess robustness against concept drift.
**Results:** The proposed hybrid GNN-XGBoost model achieved an Area Under the Precision-Recall Curve (AUC-PR) of **0.6990**, significantly outperforming the vanilla XGBoost baseline (0.6639) and Random Forest (0.5646). Crucially, the hybrid model demonstrated superior precision at high recall thresholds and successfully identified 13 complex fraud rings that standard models missed.
**Conclusion:** The findings confirm that while legitimate users often exhibit high connectivity, the *nature* of connectivity differs for fraudsters. By effectively encoding these structural patterns, the improved hybrid architecture provides a significant operational advantage, reducing false positives while capturing collusive behavior that would otherwise go undetected.

**Keywords:** Fraud Detection, Graph Neural Networks, XGBoost, Real Estate, Concept Drift, Heterogeneous Graphs.
