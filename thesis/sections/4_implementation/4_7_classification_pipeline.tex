\section{Classification Pipeline}
\label{sec:4_7}

The final component of our framework is the classification pipeline, which uses an XGBoost model to validate the patterns discovered by the GNN. This pipeline is implemented in \texttt{src/models/xgboost\_classifier.py} and includes full integration with Optuna for hyperparameter optimization.

\subsection{Hybrid Pipeline}
\label{sec:4_7_1}

The hybrid pipeline works by concatenating traditional tabular features with the graph embeddings generated by the GNN. The training process for this hybrid model is outlined in Algorithm~\ref{alg:hybrid_training}.

\begin{algorithm}[H]
\caption{Hybrid Training Pipeline}
\label{alg:hybrid_training}
\begin{algorithmic}[1]
\REQUIRE Training dataframe $\mathcal{D}_{train}$, heterogeneous graph $\mathcal{G}$, trained GNN model $\theta_{GNN}$, XGBoost hyperparameters $\mathcal{P}_{XGB}$
\ENSURE Trained hybrid classifier $f_{hybrid}$
\STATE Set GNN to evaluation mode: $\theta_{GNN}.eval()$
\STATE Generate embeddings without gradient computation:
\STATE \quad $\mathbf{H} \gets \theta_{GNN}(\mathcal{G}.x_{dict}, \mathcal{G}.edge\_index_{dict})$
\STATE Extract listing embeddings: $\mathbf{H}_{listing} \gets \mathbf{H}[\text{"listing"}] \in \mathbb{R}^{N \times 16}$
\STATE Load tabular features: $\mathbf{X}_{tabular} \gets \mathcal{D}_{train}[\text{FEATURE\_COLUMNS}] \in \mathbb{R}^{N \times 65}$
\STATE Concatenate features: $\mathbf{X}_{hybrid} \gets [\mathbf{X}_{tabular} \mid \mathbf{H}_{listing}] \in \mathbb{R}^{N \times 81}$
\STATE Initialize XGBoost classifier: $f_{XGB} \gets \text{XGBClassifier}(\mathcal{P}_{XGB})$
\STATE Train classifier: $f_{XGB}.fit(\mathbf{X}_{hybrid}, \mathcal{D}_{train}[\text{"is\_fraud"}])$
\RETURN Trained hybrid model $f_{hybrid} \gets f_{XGB}$
\end{algorithmic}
\end{algorithm}

\subsection{XGBoost Training and Optimization}
\label{sec:4_7_2}

We use Optuna with a Tree-structured Parzen Estimator (TPE) sampler to optimize the model's hyperparameters. Over 50 trials, the sampler explores a range of configurations, including the number of estimators (50 to 500), the maximum tree depth (3 to 12), and the learning rate (0.01 to 0.3). We also tune the subsample and column sample rates, along with the \texttt{scale\_pos\_weight} parameter to account for the imbalanced nature of the dataset.

Each configuration is evaluated using 5-fold cross-validation with AUC-PR as the primary objective. The TPE algorithm updates its understanding of the search space after each trial, gradually concentrating its efforts on high-performing regions. Once the best parameters are found, they are logged to MLflow and saved for use in production.

\subsection{Training Pipeline Architecture}

The pipeline supports two distinct modes of operation depending on the needs of the experiment:

\paragraph{Single Training Mode}
This mode uses a fixed temporal split to evaluate model performance under stable conditions. It involves loading the merged events, applying a temporal split with a 7-day gap (training on data up to June 2025 and testing on July 2025), and building the heterogeneous graph. If a hybrid model is being used, the GNN is trained first to extract embeddings, which are then combined with the base features to train the XGBoost classifier.

\paragraph{Expanding Window Mode}
To analyze how models handle concept drift, we use an expanding window approach. This involves defining a series of temporal windows with increasing amounts of training data. For each window, we train the model, evaluate it on the subsequent period, and track any degradation in performance. This mode also incorporates drift detection methods like DDM and ADWIN to identify significant shifts in the underlying data distribution.

\subsection{Hyperparameter Optimization Strategy}

We employ a two-stage optimization strategy to manage the computational cost of tuning both the GNN and XGBoost components:

\paragraph{Stage 1: XGBoost Optimization}
In the first stage, we run 50 trials to find the optimal XGBoost parameters while keeping the GNN embeddings fixed. We focus on maximizing AUC-PR and use early stopping to prevent overfitting.

\paragraph{Stage 2: Joint GNN+XGBoost Optimization}
In the second stage, we fix the XGBoost parameters found in Stage 1 and run another 30 trials to tune the GNN's hidden dimensions, output sizes, and number of layers. This allow us to find a high-performing joint configuration—such as a 2-layer GNN with a 32-dimensional hidden layer—without the prohibitive cost of an exhaustive joint search.

\subsection{Model Training Flow}

The overall training flow begins with data loading and the temporal split, followed by the construction of the heterogeneous graph. For hybrid models, the GNN is trained using supervised node classification with binary cross-entropy loss and the Adam optimizer. We found that five epochs were sufficient for the GNN to converge. Once trained, the GNN generates deterministic embeddings that are then concatenated with the base attributes for the final XGBoost training stage.
