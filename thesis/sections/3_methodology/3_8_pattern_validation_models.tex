\section{Pattern Validation: Classification Models}
\label{sec:3_8}

To determine if the patterns discovered by our graph analysis carry genuine predictive power, we use a series of classification models. These models act as the final validation step, comparing the performance of standard attribute-based detection against our graph-augmented approach.

\subsection{Baseline Models}

We established two baseline models to serve as a performance floor for our experiments.

\paragraph{Logistic Regression}
This linear model provides a simple baseline with highly interpretable coefficients. We configured it using L2 regularization and class weight balancing to handle the dataset's skew. This allows us to see if a simple linear combination of features is sufficient for fraud detection in this domain.

\paragraph{Random Forest}
As a tree-based ensemble, the Random Forest model captures non-linear interactions between features without relying on graph information. Our configuration used 100 trees with a maximum depth of 10 and balanced class weights. This baseline represents the level of performance achievable through non-linear modeling of tabular data alone.

\subsection{XGBoost Configuration}

XGBoost was selected as our primary classifier due to its proven effectiveness on tabular datasets. We optimized its hyperparameters using Optuna's Tree-structured Parzen Estimator (TPE) sampler over 50 trials, focusing on maximizing the AUC-PR.

To handle class imbalance, we opted for cost-sensitive learning rather than synthetic oversampling. By setting the \texttt{scale\_pos\_weight} to 11—which roughly matches our 1:11 fraud ratio—we increased the model's penalty for missing fraudulent listings. This approach avoids the potential artifacts introduced by synthetic data like SMOTE while integrating seamlessly with the gradient boosting process.

\subsection{Hybrid Pipeline Design}

The hybrid GNN+XGBoost pipeline is designed as a two-stage process. In the first stage, the GNN is trained on the heterogeneous graph to extract 16-dimensional relational embeddings for each listing. In the second stage, these embeddings are concatenated with the 65 base tabular features to create an enriched 81-dimensional feature vector.

This staged separation offers several advantages for our research. It allows us to debug the GNN and the classifier independently and enables us to cache embeddings for faster experimentation. More importantly, it allows for a direct SHAP analysis on the final classifier, making it possible to quantify exactly how much our graph-based patterns contribute to the model's overall predictive performance compared to traditional attributes.
